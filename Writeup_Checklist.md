# Writeup Speed-Run Checklist

## Phase 1: Gather Evidence 📸
- [ ] **Video Demonstration:** Record a quick video playing a few rounds, demonstrating the audit mechanic, using the shop phase, and briefly showing the Card Creator tool in action.
- [ ] **Mandatory Links:**
  - [ ] Build Link (Playable game/prototype)
  - [ ] API Reference Link (Card creator class/struct docs if any)
  - [ ] User Guide Link
- [ ] **Blueprint/Code Screenshots:**
  - [ ] Core loop logic (e.g., multiplier calc). *Tip: Collapse nodes to functions/macros if the graph is too big, or use blueprintue.com.*
  - [ ] Auditing logic.
  - [ ] A complex bug you encountered and its fix.
- [ ] **Tool & Architecture Screenshots:**
  - [ ] Card Creator tool UI inside Unreal editor.
  - [ ] Data folder structure showing file organisation intended to prevent Git conflicts.
- [ ] **Research Sources:**
  - [ ] Notes + Link/Screenshot for *Liar's Bar* (Include publisher name).
  - [ ] Notes + Link for Unreal Engine Docs regarding Data Assets.
  - [ ] Find and take notes on one academic source regarding game design or architecture.
- [ ] **Testing Details:**
  - [ ] Prepare rough testing data (specs, FPS, bugs found) to put in the template's table.
  - [ ] Find 1-2 screenshots of the game / UI interactions taken during a playtest.
- [ ] **Asset & AI List:**
  - [ ] Quick list of any 3rd-party assets, UI packs, or AI tools (ChatGPT, Copilot) used during development.

## Phase 2: Power-Drafting 📝
*Goal: Just get the facts down in bullet points. Do not worry about grammar yet.*
- [ ] Open `Commentary_Questions.md`.
- [ ] Fill out the Front Matter links.
- [ ] Bullet-point draft the Abstract.
- [ ] Bullet-point draft the Research section (evaluate your 3 sources).
- [ ] Bullet-point draft the Implementation details (Process, Git architecture, Roadblocks).
- [ ] Draft Testing observations and reflection.
- [ ] Bullet-point draft the Critical Reflection (specifically highlighting what exceeded expectations and what didn't work).

## Phase 3: Assembly & Refinement 🏗️
- [ ] Open `development-commentary-template.md`.
- [ ] Transfer your bullet points from Phase 2 into flowing paragraphs under the correct template headings.
- [ ] Insert the screenshots and videos you gathered in Phase 1 directly into the document near relevant paragraphs.
- [ ] (Optional) Add blueprintue.com links for your massive blueprints.

## Phase 4: Final Polish ✨
- [ ] **Formatting:** Use UCA's Harvard formatting for your bibliography.
- [ ] **Citations:** Ensure you have inline citations/hyperlinks for games, software, and docs.
- [ ] **Word Count Check:** Ensure your final word count is within ±10% of the target guideline.
- [ ] **Asset Declaration:** Formally declare all AI & 3rd party assets in the bottom section.
- [ ] **Link Verification:** Click every link (Video, Build, Sources) in an incognito window to ensure they work.
- [ ] **Submit!**
